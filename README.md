# vivo／iQOO 动态照片转换工具

将一张 JPG/JPEG 静态照片和一段 MP4 视频转换为 vivo／iQOO 系统相册可识别的双文件动态照片。支持 Windows 拖拽转换、文件选择和批量处理，无需第三方 Python 库。

**已在 iQOO Neo9 的一个系统环境中验证样本方案，可以识别并正常播放。其他机型和系统版本未验证。**

系统相册能播放，不代表微信朋友圈、小红书、抖音等平台一定支持以实况形式发布。本项目与 vivo、iQOO、微信及其他平台没有官方关联。

## 目录结构

本说明中的 `./` 表示工具所在目录，与盘符及文件夹名称无关。

```text
./
├── README.md
├── LICENSE
├── .gitignore
├── 拖入图片视频转换.bat
├── vivo_convert.py
├── vivo_profile.json
└── 转换结果/                 # 运行时自动创建，不提交到 GitHub
```

| 相对路径 | 用途 |
| --- | --- |
| `./README.md` | 使用说明 |
| `./LICENSE` | 原创代码和文档的 MIT 许可证 |
| `./.gitignore` | 排除生成结果、缓存及媒体素材 |
| `./拖入图片视频转换.bat` | 启动入口，支持拖拽和双击 |
| `./vivo_convert.py` | 转换程序 |

| `./转换结果/` | 转换结果和日志 |

启动文件、转换程序和配对模板必须放在同一目录，不要单独移动或更改文件名。

## 运行要求

- Windows 系统。
- Python 3.8 或以上版本，命令行可以使用 `python` 或 `py`。
- 双击选择文件功能需要 Tkinter，Windows 官方 Python 安装包通常包含该组件。
- 工具所在目录有写入权限。

无需安装第三方 Python 库，转换过程不需要联网。可以整体移动工具文件夹，无需修改盘符或配置路径。

## 支持格式

- 图片：`.jpg`、`.jpeg`。
- 视频：`.mp4`。
- 不支持直接输入 PNG、HEIC、GIF 等图片格式。

建议使用 H.264 视频编码和 AAC 音频编码的 MP4。工具不会自动转换编码、剪辑视频、调整方向或匹配封面画面。MP4 容器结构通过检查，不代表其中的编码一定能在手机播放。

请使用未转换过的原始素材。已有动态尾部信息的 JPG，或已带 vivo 配对信息的 MP4，会被拒绝处理。

## 使用方法

### 拖拽转换单组文件

1. 准备一张 JPG/JPEG 图片和一个 MP4 视频。
2. 同时选中这两个文件。
3. 将它们一起拖到 `./拖入图片视频转换.bat` 上。
4. 等待转换完成，输出文件夹会自动打开。

仅输入一张图片和一个视频时，两者可以不同名，也可以来自不同目录。图片用作静态画面，视频用作动态播放内容。

### 拖拽文件夹批量转换

每组图片和视频放在同一目录，主文件名一致，例如：

```text
./素材/
├── 001.jpg
├── 001.mp4
├── 002.jpeg
└── 002.mp4
```

将素材文件夹拖到 `./拖入图片视频转换.bat` 上即可。素材文件夹也可以放在工具目录以外。

工具会递归扫描子文件夹，按“同目录、同主文件名”配对。无法唯一配对的文件会跳过。例如，同目录下同时存在 `001.jpg`、`001.jpeg` 和 `001.mp4` 时，无法确定使用哪张图片。

如果扫描结果总共只有一张图片和一个视频，则按单组规则直接配对，允许不同名。自动扫描时仅收集 JPG/JPEG 和 MP4，其他格式文件不计入跳过统计；直接拖入不支持的文件会记录提示。

### 双击选择文件

双击 `./拖入图片视频转换.bat`，在弹出的窗口中同时选择图片和视频。单组和批量配对规则与拖拽时一致。取消选择则结束运行，不创建结果目录。

### 命令行运行（可选）

在工具根目录打开 CMD，可以使用相对路径：

```cmd
python vivo_convert.py "./素材/001.jpg" "./素材/001.mp4"
```

也可以扫描文件夹：

```cmd
python vivo_convert.py "./素材"
```

素材的相对路径按当前命令行目录解释；配置和输出始终按工具所在目录定位。

## 输出位置与日志

结果保存在 `./转换结果/`。每次运行建立独立子文件夹，例如：

```text
./转换结果/20261017_120000_a1b2c3/
├── 001_vivo_XXXXXXXX.jpg
├── 001_vivo_XXXXXXXX.mp4
└── 转换记录.txt
```

- 每组输出包含同名 JPG 和 MP4，内部写入匹配的新实况关联 ID。
- 窗口和 `转换记录.txt` 记录成功组数、失败组数、跳过文件数及相关原因。
- 没有可转换配对时也会生成日志；取消文件选择、模板损坏或输出目录无法写入等提前结束情况除外。
- 成功后自动打开本次输出目录；若未打开，可手动进入 `./转换结果/`。
- 不删除或覆盖原始素材，不重新编码图片或视频。
- 对使用开放长度末尾数据块的 MP4，会调整该数据块的长度，以便追加配对元数据。

结束状态码：`0` 表示所有选定素材均成功处理或用户取消选择；`1` 表示转换失败、没有配对或发生错误；`2` 表示至少一组转换成功，但有素材被跳过且没有转换失败。BAT 启动文件在暂停后保留相同状态码。

## 传输到手机

1. 将生成的 JPG 和 MP4 一起复制到手机。
2. 两个文件放在手机的同一个目录，保持生成时的同名关系。
3. 打开系统相册，检查动态标识并播放。

建议通过 USB 复制，或者将两个文件打包成 ZIP，传到手机后解压。不要通过聊天软件按普通图片发送，以免重新编码导致配对元数据丢失。

不要只传 JPG，也不要删除、单独改名或移动配套 MP4。普通修图工具重新保存 JPG 也可能破坏动态照片信息。

## 常见问题

### 没有可转换配对

确认包含 JPG/JPEG 和 MP4。批量时检查每组是否同目录、同主文件名，且不存在重复候选图片。查看本次 `转换记录.txt` 中的跳过原因。

### 提示找不到 Python

安装 Python 3.8 或以上，在安装时勾选“Add Python to PATH”，然后重新启动工具。

### 双击无法打开文件选择窗口

检查 Python 是否包含 Tkinter，也可直接拖入图片和视频转换。

### 提示已有配对信息或不是普通 JPG

改用未转换的原始素材，不要对生成结果重复转换。

### 个别文件转换失败

查看窗口提示及本次输出目录中的 `转换记录.txt`，确认输入文件完整且输出目录可写。

### 手机没有动态标识或无法播放

确认两个文件都已完整传输、同名且同目录，然后重新打开相册。仍然失败时检查机型、系统版本和视频编码兼容性。

## 实现依据、来源与限制

本项目的配对程序在本次开发中编写：读取 JPG 和 MP4，分别追加从正常样本提取的 vivo 元数据，并写入相同的新关联 ID。没有直接复制此前使用的 MotionPhotoConverter 项目的代码，也不依赖该项目。Python 的导入项全部来自标准库。

`./vivo_profile.json` 提取自用户提供的、微信保存后在手机相册正常播放的一对 JPG/MP4。模板仅保留 JPEG 尾部和 MP4 的 vivo 扩展块，不包含照片画面或视频媒体数据。模板包含样本配对 ID 和用途未完全明确的二进制字段；配对 ID 在生成新文件时替换，其他字段沿用样本。

厂商字段的完整含义、校验方式及不同系统的识别规则尚未完全明确。模板使用样本中的封面时间和旋转设置，不提供自定义封面时间或方向调整。暂不保证特殊旋转素材、其他设备或后续系统升级后的兼容性。
